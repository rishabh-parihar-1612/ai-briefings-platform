The Statistics Nobody Does

A 3-point gap is usually noise · evals › eval-statistics

coremixed confidence2026-09-10

Hook

A 3-point difference on a 100-case eval set is usually well inside the confidence interval — most eval decisions are made on noise, not signal.

Mental model

Compare variants paired on the same cases, not as two independent averages, and report an interval, not a point estimate. That single change stops most random-walk iteration.

Decide

Use when a release decision rides on the eval delta
  • Two prompts, models, or pipeline changes are being compared for a ship/no-ship call
  • The eval set is small enough that a few flipped cases could swing the headline number
  • A judge's agreement with human labels has never been measured
Skip when the statistics add cost without changing the decision
  • The effect size is large and obvious (a broken tool call, not a 2-point wobble)
  • The comparison is exploratory, pre-release, informal iteration
  • No held-out cases exist yet to pair or bootstrap over

Aryaka

A prompt change to the NetDevOps RCA drafter moves the eval score from 87% to 90% on a 100-case set. Before shipping, a paired bootstrap comparison over those same 100 cases is the honest question — a 3-point gap on 100 cases frequently sits inside the confidence interval, meaning the "improvement" could be 3 flipped cases, not a real change. The judge itself is checked against 30 human-labeled RCAs for agreement (a kappa statistic) before either score is trusted, since a judge preferring new phrasing produces the exact same 3-point movement.

Say this

The first thing I'd fix is that most eval decisions are made on noise — I'd move to paired comparison with bootstrap confidence intervals so a 3-point gap stops driving ship decisions.

Trap

Reporting a single eval score as the release decision. The tell: nobody can say whether a 3-point improvement would still show up if 5 cases in the set were swapped for 5 different ones.

Probe

Variant B scores 3 points higher than Variant A on a 100-case eval set. Should you ship B?
Show answer

Not on that number alone — a 3-point gap on 100 cases is frequently inside the bootstrap confidence interval. Run a paired comparison (same cases, both variants, analyze the deltas) and report the interval before treating the gap as a real effect.

Does running a model at temperature 0 make its output deterministic across runs?
Show answer

No — it reduces variance but does not guarantee bit-identical output; batching and hardware nondeterminism still introduce variation. Treating a single temperature-0 run as reproducible ground truth is a common and incorrect assumption.

How do you know whether your eval set is even large enough to detect the size of change you're testing for?
Show answer

Power analysis — sizing the eval set against the minimum effect size you need to detect, before running the comparison. A 20–100 case set can easily be too small to reliably distinguish a small prompt change, which is exactly the case paired bootstrap CIs are meant to catch.
