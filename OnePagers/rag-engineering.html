RAG Engineering

Hook

Buying a vector database gets you approximately none of the way there. RAG quality comes from the pipeline around it, not the database itself.

Mental model

Structure survives ingestion, or it doesn't come back. Retrieve wide with fusion, narrow with a reranker, and measure the result — or you're managing a vibe, not a system.

Decide

Use when build the full pipeline
  • The corpus has real structure — headings, tables, procedures — worth preserving
  • Exact identifiers (error codes, CLI strings, IDs) appear in real queries
  • A held-out eval set can be built before tuning starts
Skip when
  • The corpus is small enough a human already knows every document
  • No structure exists to parse — flat, unstructured prose only
  • Query patterns are still unknown — too early to fix a chunking strategy

Aryaka

Aryaka's Benji/CBIH support RAG parses Confluence runbooks and configs into a structured document tree before chunking — a BGP neighbor config block stays one semantic chunk, tagged vendor:juniper, protocol:bgp, never split at 512 tokens. Each chunk carries its heading path ("Site Health > Site Stability > Tunnel Coverage") so "coverage ≤80% indicates unstable" retrieves with its context intact. Retrieval runs hybrid — pgvector alongside Postgres full-text search, fused, then reranked to the top 5 — so show vpn tunnel status matches on exact string where pure embeddings would only find "VPN troubleshooting" generally. The pipeline stays on Postgres+pgvector rather than a fourth database, phased: foundation, hybrid+rerank, network-aware chunkers, then a 100–300-question eval set.

Say this

RAG quality is a pipeline, not a database — chunking, fusion, reranking, and an eval set that measures Recall@k and groundedness, not a vector store you bought.

Trap

Treating the vector database purchase as the RAG project. The tell: nobody can explain why a specific chunk was or wasn't retrieved for a specific question, because no eval dataset exists to even ask that quantitatively.

Probe

A support query "show vpn tunnel status" retrieves generic VPN troubleshooting docs instead of the exact command reference. Why?
Show answer

Pure vector search smooths past exact strings — error codes, CLI commands, and IDs are a lexical-match problem, not a "similar meaning" problem. Hybrid retrieval (BM25 + vector, fused) catches what embeddings alone miss.

Should a 12-row BGP config block be split into 512-token chunks like the surrounding prose?
Show answer

No — a config stanza is one semantic unit regardless of token count. Splitting it destroys the complete, runnable block that made it useful; the natural chunk unit differs by content type.

How do you actually know if a RAG pipeline change — new chunker, new reranker — helped or hurt?
Show answer

A frozen eval set of 100–300 real questions with expected source/section per question, scored on Recall@k, MRR, groundedness and citation correctness — compared before and after, not judged by reading a few answers.
